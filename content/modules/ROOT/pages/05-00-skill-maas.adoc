= Crear skill `configure-maas`

Los *skills* de OpenCode son instrucciones versionadas en archivos `SKILL.md` que OpenCode carga bajo demanda. Los guardamos en el pod en `$HOME/.config/opencode/skills/<nombre>/SKILL.md`.

En este módulo creamos dentro de OpenCode el skill `configure-maas`, que configura *Models as a Service* en el cluster:

. `GatewayClass/openshift-default` (el controller Gateway API ya corre en el cluster: `istiod-openshift-gateway`)
. Instancia *Kuadrant* en `kuadrant-system` (Authorino + Limitador; OLM reutiliza el Authorino pre-instalado)
. Postgres + secret `maas-db-config` (namespace `redhat-ai-gateway-infra`)
. Gateway `maas-default-gateway` (namespace `openshift-ingress`, Gateway API)
. `aigateway.modelsAsAService: Managed` en el `DataScienceCluster`

== Contenido del skill

El skill está en el repo: `skills/configure-maas/SKILL.md`. Su cuerpo le indica a OpenCode:

* Clonar el repo https://github.com/pkstaz/rhoai-showroom[rhoai-showroom] (si no existe) y entrar (`cd rhoai-showroom`); todos los manifiestos vienen de ahí
* Aplicar `manifests/maas/gatewayclass.yaml` y esperar `Accepted=True`, luego esperar el rollout de `istiod-openshift-gateway` (antes de Kuadrant)
* Crear la instancia Kuadrant (`manifests/maas/kuadrant.yaml`) y esperar `Ready` (con troubleshooting si el Operator no detecta el provider de Gateway API)
* Aplicar `manifests/maas/maas-postgres.yaml` y esperar el pod `Running`
* Ejecutar `bash manifests/apply-maas-gateway.sh` (crea el Gateway con el certificado default del cluster) y esperar `Programmed=True`
* Parchear el DSC: `aigateway` + `modelsAsAService` en `Managed` y esperar los pods `maas-api` / `maas-controller` en `Running`
* Reportar al final el estado de cada paso (no seguir si algo falla) y salir del repo (`cd ..`)

== Crear el skill desde OpenCode

El repo ya está clonado dentro del pod (`/opt/app/repo`), así que desde OpenCode pídele:

....
Usando el contenido de skills/configure-maas/SKILL.md del repo,
crea el skill configure-maas en ~/.config/opencode/skills/configure-maas/SKILL.md.
....

O créalo tú directamente:

[source,bash]
----
oc -n opencode exec -it deploy/opencode-agent -- /bin/sh -c \
  'mkdir -p ~/.config/opencode/skills/configure-maas &&
   cp /opt/app/repo/skills/configure-maas/SKILL.md ~/.config/opencode/skills/configure-maas/SKILL.md'
----

== Formato del SKILL.md

[source,markdown]
----
---
name: configure-maas
description: Configura Models as a Service (MaaS) en este cluster
  OpenShift AI: postgres, gateway MaaS y aigateway.modelsAsAService
  en el DataScienceCluster. Usar cuando el usuario pida habilitar o
  configurar MaaS.
---

(instrucciones paso a paso...)
----

El `description` es lo que OpenCode usa para decidir *cuándo* activar el skill; el cuerpo define *qué hace*.

== Verificar

En OpenCode, `ls ~/.config/opencode/skills/configure-maas/` debe listar el `SKILL.md`.
