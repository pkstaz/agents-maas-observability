= Skill observabilidad de tokens

Creamos y ejecutamos en OpenCode el segundo skill: `enable-observability`. Habilita el stack de observabilidad de MaaS para ver los *tokens* que OpenCode está generando con este mismo stack (usage logging + dashboards).

== Qué hace el skill

. Instala los operadores: *Tempo*, *OpenTelemetry*, *Cluster Observability Operator* y *Loki*
. Configura el monitoreo del DSCI (dashboards Perses, trazas)
. Enciende la telemetría del gateway MaaS (`maastenantconfig`)
. Despliega *MinIO + LokiStack* (usage logging)
. Enciende `usageLogging` en `configs.maas.opendatahub.io`

== Contenido del skill

El skill está en el repo: `skills/enable-observability/SKILL.md`. Le indica a OpenCode:

* Clonar el repo https://github.com/pkstaz/rhoai-showroom[rhoai-showroom] (si no existe) y entrar (`cd rhoai-showroom`)
* Ejecutar `bash manifests/apply-maas-observability.sh`
* Esperar cada operador (`CSV` en `Succeeded`), LokiStack `Ready` y el patch de `usageLogging`
* Verificar al final que `usageLogging` está encendido y salir del repo (`cd ..`)

== Ejecutar desde OpenCode

El despliegue ya instala el skill (el entrypoint del pod lo copia a `~/.config/opencode/skills/`). En OpenCode pídele:

....
Ejecuta el skill enable-observability.
....

== Qué instala

[cols="1,2"]
|===
|Componente |Detalle

|Tempo / OTEL
|Trazas del gateway y del stack de inferencia.

|Cluster Observability Operator
|Dashboards (Perses) de uso.

|Loki + MinIO + usage logging
|Registro de uso por API key: tokens de entrada/salida por request.
|===

Los waits largos son los operadores (varios minutos cada uno).

== Ver los tokens

. Generá tráfico con OpenCode (preguntas de código).
. Abrí *RHOAI → Observe & monitor → Dashboards* y busca los dashboards de uso/usage.
. En *RHOAI → Models as a Service → API keys / usage*, verifica el consumo de la key `opencode-workshop`.

== Verificar

[source,bash]
----
oc get configs.maas.opendatahub.io default -o jsonpath='{.spec.usageLogging}'; echo
oc get lokistack usage -n redhat-ods-monitoring
oc get persesdashboard -n redhat-ods-monitoring
----
