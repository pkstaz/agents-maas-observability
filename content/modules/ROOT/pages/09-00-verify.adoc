= Verificación final

Checklist end-to-end del stack que dejaste funcionando: OpenCode → MaaS → observabilidad de tokens.

== Checklist

[cols="1,3"]
|===
|Componente |Verificación

|Modelo base detenido
|`oc get pods -n my-first-model` sin pods del modelo (`minReplicas=0`); GPU libre.

|Modelo L4
|`oc get llminferenceservice qwen25-coder-7b-awq -n llm` en `Ready`.

|OpenCode
|`oc get route opencode-agent -n $NS` responde; OpenCode conectado con el modelo MaaS.

|Skills
|`ls ~/.config/opencode/skills/` (en el pod) lista `configure-maas` y `enable-observability`.

|MaaS
|`oc get gateway maas-default-gateway -n openshift-ingress` en `Programmed`; `maas-api` / `maas-controller` en `Running`.

|Modelo publicado
|`oc get maasmodelref qwen25-coder-7b-awq -n llm` en `Ready`; visible en *RHOAI → Models as a Service*.

|Observabilidad
|`oc get configs.maas.opendatahub.io default -o jsonpath='{.spec.usageLogging}'` = `true`; dashboards de uso en RHOAI.
|===

== E2E completo

. En OpenCode, generá varias respuestas de código.
. Abrí *RHOAI → Models as a Service* → uso de la API key `opencode-workshop`: deben aparecer los requests y los tokens.
. Abrí *RHOAI → Observe & monitor → Dashboards*: dashboards de uso con los tokens de entrada/salida.

CAUTION: Si el uso no aparece, verificá que el `LLMInferenceService` tenga `--enable-force-include-usage` (módulo 3) y que `usageLogging` esté encendido (módulo 8).
