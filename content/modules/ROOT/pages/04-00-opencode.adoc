= Desplegar OpenCode

Desplegamos *OpenCode* como pod en el cluster. Trae `oc` + `kubectl`, corre `opencode serve` y queda expuesto por una *Route*. El pod usa un ServiceAccount con `cluster-admin` (*solo workshop*): es lo que permite que los skills del módulo 6 y 8 administren el cluster desde OpenCode.

Requisitos: modelo L4 `Ready` (módulo 3).
Manifiestos: `manifests/opencode/` (namespace, build, deploy, config).

== Qué crea este módulo

[cols="1,2"]
|===
|Recurso |Detalle

|Namespace `opencode`
|El proyecto de OpenCode.

|`ImageStream` + `BuildConfig/opencode-agent`
|Imagen con `opencode-ai` + cliente `oc` (Dockerfile inline, build en el registry interno).

|`ServiceAccount/opencode-agent` + ClusterRoleBinding
|`cluster-admin` (*workshop-only*). El token del SA monta automáticamente en el pod y `oc` lo usa.

|`ConfigMap/opencode-config`
|`opencode.jsonc` con el proveedor Qwen L4 (baseURL de la ruta del módulo 3).

|`Deployment/Service/Route`
|`opencode serve` en el puerto 4096 + ruta HTTPS.

|Repo del workshop
|El pod clona automáticamente el repo (env `REPO_URL`, default el repo del workshop) en `/opt/app/repo` y corre OpenCode desde ahí: los `manifests/` y `skills/` del repo ya están disponibles para el agente.
|===

== 1. Crear el proyecto

[source,bash]
----
oc apply -f manifests/opencode/00-namespace.yaml
----

== 2. Construir la imagen

El `BuildConfig` lleva el Dockerfile inline (instala `opencode-ai` y el cliente `oc`):

[source,bash]
----
oc apply -f manifests/opencode/01-buildconfig.yaml
oc start-build opencode-agent -n opencode --follow
----

El build corre `npm install`: tarda unos minutos. Esperá `Pushed image...` o salí con `Ctrl-C` y verifica con `oc get builds -n opencode`.

== 3. Configurar el modelo

Saca la URL del modelo (módulo 3) y reemplaza el placeholder en el ConfigMap:

[source,bash]
----
URL=$(oc get llminferenceservice qwen25-coder-7b-awq -n my-first-model -o jsonpath='{.status.url}')
sed "s|<MODEL_URL>|${URL}|g" manifests/opencode/03-configmap.yaml | oc apply -f -
----

El ConfigMap deja `opencode.jsonc` con el proveedor `qwen-l4` apuntando a `${URL}/v1`.

== 4. Desplegar

[source,bash]
----
oc apply -f manifests/opencode/02-deploy.yaml
oc rollout status deploy/opencode-agent -n opencode --timeout=300s
----

.02-deploy.yaml (click para expandir)
[%collapsible]
====
[source,yaml]
----
# OpenCode pod (opencode serve + oc), namespace fijo `opencode`.
apiVersion: v1
kind: ServiceAccount
metadata:
  name: opencode-agent
  namespace: opencode
---
# Workshop-only: OpenCode administra el cluster via skills.
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: opencode-agent-cluster-admin
subjects:
  - kind: ServiceAccount
    name: opencode-agent
    namespace: opencode
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: opencode-agent
  namespace: opencode
  labels:
    app: opencode-agent
    opendatahub.io/dashboard: "true"
spec:
  replicas: 1
  selector:
    matchLabels:
      app: opencode-agent
  template:
    metadata:
      labels:
        app: opencode-agent
        opendatahub.io/dashboard: "true"
    spec:
      serviceAccountName: opencode-agent
      volumes:
        - name: tmp
          emptyDir: {}
        - name: repo
          emptyDir: {}
        - name: config
          configMap:
            name: opencode-config
      containers:
        - name: opencode
          image: image-registry.openshift-image-registry.svc:5000/opencode/opencode-agent:latest
          imagePullPolicy: Always
          volumeMounts:
            - name: tmp
              mountPath: /tmp
            - name: repo
              mountPath: /opt/app/repo
            - name: config
              mountPath: /opt/app-secrets/opencode.jsonc
              subPath: opencode.jsonc
          env:
            - name: REPO_URL
              value: https://github.com/pkstaz/opencode-maas-observability-workshop.git
          command: ["/bin/sh", "-c"]
          args:
            - >-
              mkdir -p $HOME/.config/opencode &&
              cp /opt/app-secrets/opencode.jsonc $HOME/.config/opencode/opencode.json &&
              git config --global --add safe.directory /opt/app/repo &&
              if [ ! -d /opt/app/repo/.git ]; then git clone --depth 1 ${REPO_URL} /opt/app/repo; fi &&
              cd /opt/app/repo &&
              exec /opt/app/node_modules/.bin/opencode serve --hostname 0.0.0.0 --port 4096 --cors https://app.opencode.ai
          ports:
            - containerPort: 4096
              name: http
          readinessProbe:
            httpGet:
              path: /global/health
              port: http
            initialDelaySeconds: 10
            periodSeconds: 10
          livenessProbe:
            httpGet:
              path: /global/health
              port: http
            initialDelaySeconds: 30
            periodSeconds: 30
          resources:
            requests:
              cpu: 100m
              memory: 256Mi
            limits:
              cpu: "1"
              memory: 2Gi
---
apiVersion: v1
kind: Service
metadata:
  name: opencode-agent
  namespace: opencode
  labels:
    app: opencode-agent
spec:
  selector:
    app: opencode-agent
  ports:
    - name: http
      port: 4096
      targetPort: http
---
apiVersion: route.openshift.io/v1
kind: Route
metadata:
  name: opencode-agent
  namespace: opencode
  labels:
    app: opencode-agent
spec:
  to:
    kind: Service
    name: opencode-agent
  port:
    targetPort: http
  tls:
    termination: edge
    insecureEdgeTerminationPolicy: Redirect
----
====

== Entrar a OpenCode

Dos opciones:

* *Web UI*: abre https://app.opencode.ai, conecta un servidor remoto con la ruta del pod:

[source,bash]
----
oc -n opencode get route opencode-agent -o jsonpath='{.spec.host}'; echo
----

* *TUI* (terminal): dentro del pod:

[source,bash]
----
oc -n opencode exec -it deploy/opencode-agent -- /opt/app/node_modules/.bin/opencode
----

== Verificar el modelo configurado

En OpenCode, pregúntale algo de código (p. ej. *"escribe una función python que invierta un string"*). La respuesta debe venir del modelo Qwen L4 del módulo 3. Puedes confirmar el modelo activo con `/models` en la TUI.

CAUTION: `{l4-model}` es *text-only*: no le pases imágenes al chat (OpenCode fallará con `this model does not support image input`).
