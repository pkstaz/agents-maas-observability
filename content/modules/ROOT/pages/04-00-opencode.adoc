= Desplegar OpenCode

Desplegamos *OpenCode* como pod en el cluster. Trae `oc` + `kubectl`, corre `opencode serve` y queda expuesto por una *Route*. El pod usa un ServiceAccount con `cluster-admin` (*solo workshop*): es lo que permite que los skills del módulo 6 y 8 administren el cluster desde OpenCode.

Requisitos: modelo L4 `Ready` (módulo 3).
Manifiestos: `manifests/opencode/` (namespace, build, deploy, config).

== Qué crea este módulo

[cols="1,2"]
|===
|Recurso |Detalle

|Namespace `opencode`
|El proyecto de OpenCode.

|`ImageStream` + `BuildConfig/opencode-agent`
|Imagen con `opencode-ai` + cliente `oc` (Dockerfile inline, build en el registry interno).

|`ServiceAccount/opencode-agent` + ClusterRoleBinding
|`cluster-admin` (*workshop-only*). El token del SA monta automáticamente en el pod y `oc` lo usa.

|`ConfigMap/opencode-config`
|`opencode.jsonc` con el proveedor Qwen L4 (baseURL de la ruta del módulo 3).

|`Deployment/Service/Route`
|`opencode serve` en el puerto 4096 + ruta HTTPS.
|===

== 1. Crear el proyecto

[source,bash]
----
oc apply -f manifests/opencode/00-namespace.yaml
----

== 2. Construir la imagen

El `BuildConfig` lleva el Dockerfile inline (instala `opencode-ai` y el cliente `oc`):

[source,bash]
----
oc apply -f manifests/opencode/01-buildconfig.yaml
oc start-build opencode-agent -n opencode --follow
----

El build corre `npm install`: tarda unos minutos. Esperá `Pushed image...` o salí con `Ctrl-C` y verifica con `oc get builds -n opencode`.

== 3. Configurar el modelo

Saca la URL del modelo (módulo 3) y reemplaza el placeholder en el ConfigMap:

[source,bash]
----
URL=$(oc get llminferenceservice qwen25-coder-7b-awq -n my-first-model -o jsonpath='{.status.url}')
sed "s|<MODEL_URL>|${URL}|g" manifests/opencode/03-configmap.yaml | oc apply -f -
----

El ConfigMap deja `opencode.jsonc` con el proveedor `qwen-l4` apuntando a `${URL}/v1`.

== 4. Desplegar

[source,bash]
----
oc apply -f manifests/opencode/02-deploy.yaml
oc rollout status deploy/opencode-agent -n opencode --timeout=300s
----

== Entrar a OpenCode

Dos opciones:

* *Web UI*: abre https://app.opencode.ai, conecta un servidor remoto con la ruta del pod:

[source,bash]
----
oc -n opencode get route opencode-agent -o jsonpath='{.spec.host}'; echo
----

* *TUI* (terminal): dentro del pod:

[source,bash]
----
oc -n opencode exec -it deploy/opencode-agent -- /opt/app/node_modules/.bin/opencode
----

== Verificar el modelo configurado

En OpenCode, pregúntale algo de código (p. ej. *"escribí una función python que invierta un string"*). La respuesta debe venir del modelo Qwen L4 del módulo 3. Podés confirmar el modelo activo con `/models` en la TUI.

CAUTION: `{l4-model}` es *text-only*: no le pases imágenes al chat (OpenCode fallará con `this model does not support image input`).
