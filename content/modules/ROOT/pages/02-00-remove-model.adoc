= Eliminar modelo base `{base-model}`

El cluster trae `{base-model}` pre-configurado (KServe, proyecto `my-first-model`). Lo eliminamos por dos razones:

* *Libera la L4*: la dejamos disponible para el modelo que desplegaremos en el módulo 3.
* *Es el ejercicio*: vas a reemplazar un modelo genérico por uno optimizado para coding.

== Qué borra este módulo

[cols="1,2"]
|===
|Recurso |Detalle

|`InferenceService/llama-32-3b-instruct`
|El despliegue del modelo (KServe).

|`ServingRuntime/llama-32-3b-instruct`
|El runtime vLLM que lo sirve.

|Proyecto `my-first-model`
|Opcional: borrarlo elimina ambos recursos.
|===

== Eliminar por terminal

[source,bash]
----
oc delete isvc llama-32-3b-instruct -n my-first-model --ignore-not-found
oc delete servingruntime llama-32-3b-instruct -n my-first-model --ignore-not-found
----

O directamente el proyecto (limpia todo):

[source,bash]
----
oc delete project my-first-model --ignore-not-found
----

Esperá que el pod termine y que la GPU quede libre:

[source,bash]
----
oc get pods -n my-first-model 2>/dev/null
oc get nodes -o json | jq -r '.items[].status.allocatable | select(."nvidia.com/gpu" != null) | ."nvidia.com/gpu"'
----

== Verificar en UI

* *RHOAI → Model deployments*: `{base-model}` ya no aparece.
