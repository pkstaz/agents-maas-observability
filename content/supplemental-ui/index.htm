Skills, Agent, MaaS, Observability (metrics, logs and tracing)

Workshop sobre un cluster OpenShift AI pre-desplegado en el que vas a: desplegar un modelo Qwen3-14B-AWQ usando GPU y llm-d, desplegar OpenCode en el cluster, y usar los skills que te ayudarán a configurar Models as a Service (MaaS) y la observabilidad (metrics, logs and tracing) — todo desde OpenCode, apuntando al final a su propio Models as a Service.

Comenzar el lab Ver módulos

OpenShift AI 3.5 · NVIDIA L4 · Qwen3-14B-AWQ · llm-d · Kuadrant MaaS · OpenTelemetry + Tempo/Loki · ~2 h

Módulos

0 Introducción Narrativa del lab, requisitos, tiempos y regla del workshop. 1 Cluster pre-desplegado Explora el sandbox OpenShift AI 3.5 con el modelo base llama-3b en KServe. Empieza por 1.1 Pre-requisitos. 2 Detener modelo base Detén el InferenceService llama-3b y libera la GPU. 3 Desplegar modelo en L4 Sirve Qwen3-14B-AWQ con llm-d (LLMInferenceService) en la GPU L4. 4 Desplegar OpenCode Compila y despliega OpenCode en el cluster (BuildConfig + ruta) apuntado al modelo. 5 Habilitar MaaS Skill El OpenCode desplegado ya trae el skill configure-maas: configura el stack MaaS en el cluster (GatewayClass + Istio, Kuadrant, Postgres y gateway MaaS). 6 Ejecutar skill: MaaS Postgres, Gateway y subscription de Kuadrant aplicados por el skill. 7 OpenCode + modelo MaaS Reconfigura OpenCode para consumir el modelo vía el gateway MaaS (API key + cuotas). 8 Skill de métricas de token El OpenCode desplegado ya trae el skill enable-observability: analizamos cómo implementa cada pieza (Tempo, OpenTelemetry, COO, Loki) y encendemos el usage logging para ver los tokens generados por API key. 9 Verificación final Comprueba end-to-end: modelo en MaaS, OpenCode y métricas de tokens.
